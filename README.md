# Airbnb Listings, Reviews & Calendar Dashboard | Tableau

## 📌 Project Overview

This project focuses on visualizing Airbnb data using Tableau to explore property listings, guest reviews, and calendar information. Interactive dashboards were created to present different aspects of the data, making it easier to identify patterns, compare information, and understand Airbnb market trends.

## 🎯 Project Objectives

- Visualize Airbnb property listings and their characteristics.
- Explore guest reviews and review patterns.
- Analyze calendar data to understand listing availability and pricing trends.
- Create interactive dashboards to present insights clearly and effectively.

## 🛠️ Tools Used

- **Tableau** — Data visualization and interactive dashboard development.

## 📊 Project Workflow

### 1. Data Visualization

Explored and visualized the Airbnb listings, reviews, and calendar datasets using charts and graphs to present relevant information and highlight patterns.

### 2. Dashboard Development

Created interactive Tableau dashboards to bring the visualizations together, allowing users to explore the data and gain insights into Airbnb listings, guest reviews, and calendar trends.

## 🔍 Key Areas Explored

- **Listings:** Property information and listing characteristics.
- **Reviews:** Guest review data and review patterns.
- **Calendar:** Listing availability and pricing information over time.

## 💡 Skills Demonstrated

- Data visualization
- Tableau dashboard development
- Exploratory data analysis
- Visual storytelling
- Presenting data-driven insights

## ✅ Project Outcome

The project demonstrates how Tableau can transform Airbnb datasets into meaningful visualizations and interactive dashboards. It highlights the use of data visualization to explore property listings, guest reviews, and calendar information in an accessible and insightful way.
